# Data source register

Recorded 15 October 2026. Nothing in this table was downloaded from a public catalogue for this build.

| Dataset | Status | Use in CiviCare |
| --- | --- | --- |
| Responder profiles, certifications, shifts, incidents, assignments | Synthetic, generated by `server/src/seed.js`, seed layout version `civicare-seed-v1` | All operational records. Display names are ids such as GT-01, not personal names. |
| Project zones | Drawn for this prototype as squares around eight Chennai neighbourhood centres | Grouping and coverage only. Not official administrative boundaries. |
| Facilities | Six pins typed by hand with coordinates rounded to three decimal degrees | Map demonstration. Identity and coordinates still need a source check. |
| OpenStreetMap tiles | Used at view time from `tile.openstreetmap.org` | Basemap only. © OpenStreetMap contributors. ODbL applies to OSM data. |
| Health Infrastructure: Chennai catalogue | Not used. Not downloaded. | Candidate only: https://sandbox.data.gov.in/catalog/health-infrastructure-chennai |
| Tamil Nadu 108 / TN HSP operational data | Not requested and not used | Candidate only: https://www.tnhsp.org/pages/view/108_Application |
| Population | Not used | `zones.population_estimate` is null |

Facility rows say `approximate_sample_not_from_a_downloaded_dataset`. Do not describe them in the report as an OpenStreetMap extract or a data.gov.in extract unless that download actually happens and this file is updated with the access date, licence, and fields used.
